## 1. วัตถุประสงค์และขอบเขต
แผนการทดสอบนี้จัดทำขึ้นเพื่อปิดช่องว่างทางวิศวกรรม (Engineering Gaps) ที่ตรวจพบจากรายงาน Independent Engineering Audit โดยมุ่งเน้นการพิสูจน์พฤติกรรมของระบบใน 7 มิติสำคัญ:
1. **ชุดทดสอบ A (Timeout & Fallback):** ตรวจสอบจุดบังคับใช้ Timeout 8s ใน `app.py`, พฤติกรรมการยกเลิกงานบน Ollama, การสลับเข้าสู่ Python Fallback เมื่อเกิด Timeout/Error, และผลกระทบต่อเธรดเมื่อกด Pause/Quit
2. **ชุดทดสอบ B (HSV Boundaries & Format):** ตรวจสอบขอบเขตค่า Hue 8-bit ของ OpenCV (0–179) ที่จุดรอยต่อ (9/10/11, 24/25/26, 34/35/36, 84/85/86, 129/130/131, 154/155/156, 169/170/171) และเกณฑ์ Saturation/Value สำหรับสีดำ ขาว และเทา
3. **ชุดทดสอบ C (Local LLM Model Comparison):** เปรียบเทียบประสิทธิภาพเชิงประจักษ์ระหว่าง 3 โมเดลที่มีอยู่จริงบนเครื่อง (`qwen2.5:0.5b`, `qwen2.5:1.5b`, `llama3.2:1b`) ด้วย Prompt ภาษาไทยชุดเดียวกัน 7 สถานการณ์ รันแบบ Sequential พร้อมจำกัดเวลา 20s
4. **ชุดทดสอบ D (State Logic & Threading Controls):** ตรวจสอบตรรกะ Smart Scene Change (ฉากเดิม, ฉากเปลี่ยนเล็กน้อย, ฉากเปลี่ยนชัดเจน, ครบ 20s) และการตอบสนองต่อปุ่ม Pause/Quit
5. **ชุดทดสอบ E (End-to-End Latency Boundaries):** วัดเวลาแยกตามเหตุการณ์สำคัญ (Camera-to-Detection, Camera-to-Narrative, Camera-to-Audio-Command) ในสคริปต์ควบคุมแบบไม่เปิดเสียงจริง
6. **ชุดทดสอบ F (Distance Boundaries & Ground Truth Audit):** ตรวจสอบจุดตัดทางเรขาคณิตของ Distance Rules (`norm_bottom_y` และ `area_ratio`) และบันทึกสถานะการตรวจหาชุดข้อมูลภาพพร้อม Annotation จริง
7. **ชุดทดสอบ G (Network & Audio Mock Error Handling):** จำลองความผิดพลาดของ gTTS (ConnectionError, Timeout), ไฟล์เสียงแคชไม่พบ, และไฟล์เสียงเสียหาย เพื่อยืนยันว่า Worker Thread ไม่ค้าง

## 2. กฎความปลอดภัยและการควบคุมสภาวะแวดล้อม
- **ห้ามแก้ไขไฟล์ระบบหลัก:** `app.py`, ไฟล์โมเดล `.onnx`, `.pt`, `.ncnn.bin`, และไฟล์ผลการทดลองเดิมจะไม่มีการแก้ไขหรือเขียนทับ
- **ปิดเสียงออกลำโพง 100%:** ดำเนินการผ่าน Software-level Mock หรือปิดระดับเสียง (`volume = 0.0`)
- **ไม่ตัดสัญญาณอินเทอร์เน็ตจริง:** ใช้การจำลองข้อผิดพลาดทางเครือข่ายด้วย Mocking ในสคริปต์แยก
- **รันงานแบบ Sequential:** รันทีละโมเดลและทีละงาน เพื่อป้องกันโหลด CPU สะสม
- **เกณฑ์ตัดการทำงานอัตโนมัติ (Safety Guard):** หากอุณหภูมิแตะ 75°C, พบ Throttling, หรือ RAM เหลือ < 1 GiB ให้หยุดทันที
