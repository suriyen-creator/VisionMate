| :--- | :--- | :---: | :--- |
| **YOLO Input Size** | `target_size` | 320 × 320 พิกเซล | ลดขนาดจาก 640×640 เพื่อให้รันบน CPU ได้ความเร็วที่ยอมรับได้ |

| **Spatial Direction** | `Normalized CX Thresholds` | <0.38, 0.38–0.62, >0.62 | ซ้าย (10 นาฬิกา), ตรงหน้า (12 นาฬิกา), ขวา (2 นาฬิกา) |
| **Ollama Memory Lock** | `keep_alive` | -1 (คงค้างตลอด) | ป้องกันระบบลบโมเดลออกจาก RAM ช่วยลดเวลา Cold Start Re-load |

| **Ollama Max Predict** | `num_predict` | 45 โทเคน | จำกัดความยาวประโยคบรรยายให้กระชับไม่เกิน 2 ประโยค |
| **Ollama Temperature** | `temperature` | 0.2 | ควบคุมความคิดสร้างสรรค์ เน้นความถูกต้องของข้อเท็จจริง |
| **Ollama Threads** | `num_thread` | 4 เธรด | ใช้คอร์ CPU Cortex-A72 ทั้ง 4 คอร์เต็มประสิทธิภาพ |
