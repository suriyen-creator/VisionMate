### ตารางที่ 3.3: พารามิเตอร์การตั้งค่าของโมเดลปัญญาประดิษฐ์ในระบบ (Hyperparameters & Configurations)
| ส่วนประกอบ | ชื่อพารามิเตอร์ในโค้ด | ค่าที่กำหนด | เหตุผลเชิงวิศวกรรม |
| :--- | :--- | :---: | :--- |
| **YOLO Preprocessing** | `target_size` | 320 × 320 พิกเซล | ลดขนาดอินพุตเพื่อให้รันบน CPU RPi 4 ได้เร็วกว่า 640×640 |
| **YOLO Postprocessing** | `conf_thresh` | 0.35 | กรองวัตถุที่มีความเชื่อมั่นต่ำ ป้องกัน False Positive |
| **YOLO Postprocessing** | `nms_thresh` | 0.45 | ยุบ Bounding Box ที่ซ้อนทับกันด้วย IoU 0.45 |
| **Image Pre-check** | `Mean Brightness Cutoff` | < 25.0 | ตัดสินว่าหน้ากล้องมืดสนิท หรือถูกสิ่งของปิดทับ |

| **Spatial Direction** | `Normalized CX Boundaries` | <0.38, 0.38–0.62, >0.62 | แบ่งทิศทางซ้าย (10 นาฬิกา), หน้า (12 นาฬิกา), ขวา (2 นาฬิกา) |
| **Ollama Local LLM** | `keep_alive` | -1 (Infinite) | ตรึงโมเดลใน RAM ป้องกัน Cold Start Re-loading |
| **Ollama Local LLM** | `num_ctx` | 256 โทเคน | ประหยัด RAM (แต่พบปัญหา Context Saturation กับภาษาไทย) |
| **Ollama Local LLM** | `num_predict` | 45 โทเคน | จำกัดความยาวประโยคคำตอบไม่ให้เกิน 2 ประโยค |
| **Ollama Local LLM** | `temperature` | 0.2 | ลดความคิดสร้างสรรค์ เน้นความถูกต้องของข้อเท็จจริง |
| **Ollama Local LLM** | `num_thread` | 4 เธรด | ใช้ประสิทธิภาพทั้ง 4 คอร์ของ Cortex-A72 เต็มที่ |
| **System Hybrid Fallback**| `Ollama Timeout` | 8.0 วินาที | สลับไปใช้ Python Rule ทันทีหาก LLM ช้าเกิน 8 วินาที |
