## 1. วัตถุประสงค์และหลักเกณฑ์การกำกับคำบรรยายภาพ (Captioning Policy)

เพื่อให้เอกสารรายงานโครงงานฉบับสมบูรณ์ (`02_Project_Report.md`) และคู่มือการใช้งาน (`03_User_Manual.md`) มีความถูกต้อง น่าเชื่อถือทางวิชาการ และไม่เกิดข้อโต้แย้งในการประเมินผล:
1. **ความถูกต้องทางวิชาการ (Academic Honesty):** ทุกภาพต้องมีชื่อภาพและคำบรรยายภาษาไทยแบบทางการ ระบุชัดเจนว่าเป็นภาพหน้าจอจริง (Real Screen Capture), ภาพกราฟผลการทดลอง (Empirical Chart) หรือภาพจำลอง (Mock/Diagram)
2. **ขอบเขตการพิสูจน์ (Verifiable Boundaries):** ระบุอย่างเคร่งครัดว่าภาพนั้น **"พิสูจน์อะไรได้" (What it Proves)** และ **"พิสูจน์อะไรไม่ได้" (What it Does NOT Prove)** เพื่อไม่ให้อนุมานเกินจริง
3. **การจัดวางที่สอดคล้อง (Target Document Placement):** กำหนดตำแหน่ง หน้า และหัวข้อย่อยที่ต้องนำภาพไปแทรกในรายงาน 17 หน้า และคู่มือ 2 หน้า อย่างชัดเจน
4. **การตรวจสอบย้อนกลับ (Traceability):** ระบุชื่อไฟล์ต้นฉบับ วันเวลาที่บันทึก (Timestamp) และเครื่องมือที่ใช้จับภาพ

- **สิ่งที่ภาพนี้พิสูจน์ได้ (What it Proves):**
  1. ระบบไม่มีปัญหา Memory Leak โดยการใช้ RAM คงที่ตลอดการทำงาน
  2. อุณหภูมิสูงสุด 53.0°C อยู่ในเกณฑ์ปลอดภัยอย่างสมบูรณ์ (ต่ำกว่าเกณฑ์ตัดความเร็วที่ 80.0°C)
  3. ไม่มีการเรียกใช้หน่วยความจำเสมือน (Swap = 0 MB) บนเครื่องทดสอบ RAM 8 GB
- **สิ่งที่ภาพนี้พิสูจน์ไม่ได้ (What it DOES NOT Prove):**
  1. **ไม่ได้พิสูจน์พฤติกรรมความร้อนในการรัน Stress Test ต่อเนื่อง 10 นาทีหรือ 1 ชั่วโมง**
  2. **ไม่ได้พิสูจน์การทำงานบนบอร์ด Raspberry Pi 4 รุ่น RAM 4 GB**
- **ตำแหน่งที่แนะนำในรายงาน (`02_Project_Report.md`):**  
  - **บทที่ 4:** หน้า 12 (หัวข้อ 4.5 การใช้ทรัพยากรและอุณหภูมิ ใต้ตารางที่ 4.6)
- **ตำแหน่งที่แนะนำในคู่มือ (`03_User_Manual.md`):**  
  - ไม่จำเป็นต้องใส่ในคู่มือผู้ใช้
